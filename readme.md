# 淘宝/天猫商品数据抓取助手

这是一个基于 Python 的自动化高级工具，专为电商行业的运营、美工及数据采集需求打造，用于一键提取淘宝和天猫商品页面上的详细数据和媒体资源。

本工具不仅提供了友好的图形用户界面（GUI），并在底层使用 Playwright 配合自动翻页技术抓取数据，近期更是引入了**「沉浸式画廊挑选」**机制与 **Mac M4 Max 性能定制级内存预读取技术**，为您带来极致流畅的使用体验。

## 🌟 核心独家特性

* **内存预加载极速架构**：为大内存设备（如 Mac M4 Max）量身定制，先将高质量抓取图流转入高速统一内存（`BytesIO` Buffer）中并在后台预处理。当您点击"确定保存"时，瞬间写入物理硬盘，告别边看边挂机缓冲的网络卡顿。
* **沉浸式画廊挑选 UI**：改变了以往直接无脑下载所有图片的方式，采用自适应宽度的并排缩略图网格界面。在下载之前，赋予用户全盘控制力，您可以逐张审视文件大小并精确勾选。
* **键盘快捷挑图模式**：点击任意图片即可全屏查看大图照，且在这个大图模式中完全支持通过方向键 `←` 和 `→` 进行上一张与下一张轮播穿梭，看到满意的按 `Space`（空格键）即可勾选，操作极其顺滑连贯。
* **聪明的视频预处理与原生播放**：包含视频的商品不仅会静默极速存入临时区，还会通过底层 `OpenCV` 图像引擎自动抽帧为您提取视频封面缩略图混排在画廊中。更惊艳的是，您只要在缩略图上点一下，它会立刻无缝呼起您 Mac 系统自带的高清播放器进行全屏外放。
* **SKU 规格图自动采集**：针对多规格商品（如颜色分类、款式等），程序会在主图/详情图抓取完成后，**自动逐一点击页面上每一个规格选项**，捕获每个规格切换后的主图，以规格名称（如 `sku_扎基拉姆1送绳_1.jpg`）命名，并合并进同一个审核画廊统一让您勾选确认，完整覆盖所有不同规格的产品展示图。
* **规格图智能英文贴标 (Aliyun Translate)**：内置了图片批量加标工具。它能自动读取抓取过程中生成的 `sku_names.txt` 清单，调用阿里云电商专用翻译接口，将中文规格名翻译成精准的英文。随后，程序会在原图底部自动压上一层与底图色调和谐的色带，并居中写上英文标题。最亮眼的是，它具备**自适应字体大小**功能，当英文单词过多时会自动缩小字号以完美契合图片宽度，极大地方便了跨境电商的上架需求。
* **防污染终止与无底线清理**：在画廊底部设有鲜红色的「终止下载」按钮，一点即可全盘放弃当前抓集，程序会自动物理销毁为此次创建的缓存区影片、文件夹以及日志文本，保证您的 Mac 固态硬盘干干净净，绝不堆满垃圾。

## 🛠 原有优秀功能依然强大

* **全面数据提取**：精准区分「详情图」、「主图」、「主副视频」、「规格图」，同时爬取商品规格与交易属性参数。
* **智能反爬与拦截应对**：搭载 Playwright Stealth 增强隐蔽性。当阿里系统弹出滑块、验证码等拦截防线时能一秒敏锐识别，拉起提示音强力呼唤您在界面上手动完成即可继续作业。
* **OCR 文本识别兜底**：当网页渲染异常导致读取不到详情时，它会自动截图并动用 Tesseract OCR 文字识别引擎抢救文本，双重维稳。
* **一键直达抽屉**：全部下载落盘后，无需您穿梭目录去慢慢寻找，程序上的成功日志附带超级链接功能，鼠标轻轻一戳就能直达本地目标文件夹！

## 📁 目录与输出结构

默认情况，所有的文件将被按商品精准分类至用户目录下的 `Downloads/Taobao_Data` 内：
* **独立根文件夹**：以 `[商品ID]_[商品标题干净版]` 明确命名。
* **精美图库** (`images/`)：所有勾选过的主图（`main_x.jpg`）、长图详情（`desc_x.jpg`）以及规格图（`sku_规格名称_x.jpg`）分开命名存放。
* **视频文件**：主视频若是被您确认打勾，则以 `video_x.mp4` 落盘在商品文件夹的根深处。
* **属性总览** (`info.txt`)：清晰规整地保存目标原始链接、抓取时间和详尽规格文字版。

## ⚙️ 环境和依赖

使用前建议确保本地已经成功配置/安装以下环境：
- Python 和相关包管理环境 (`.venv` 虚拟环境）。
- `playwright` 核心及其定制浏览器环境（`playwright install chromium`）。
- `alibabacloud-alimt20181012` （用于调用阿里云翻译 API）。
- `opencv-python` （`cv2` 用于视频抽帧计算处理）。
- （可选极强推荐）配置好 Tesseract-OCR 以及对应中文字库的 `pytesseract` 环境用于破防页面变化。
