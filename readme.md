# 淘宝/天猫商品数据抓取助手 (Pro Edition)

这是一个基于 Python 的自动化高级工具，专为电商行业的运营、美工及跨境贸易数据采集需求打造，用于一键提取淘宝和天猫商品页面上的详细数据和媒体资源。

本工具不仅提供了友好的图形用户界面（GUI），并在底层使用 Playwright 配合自动翻页技术抓取数据，近期更是引入了**「沉浸式画廊挑选」**、**「SKU 翻译审核系统」**以及 **Mac M4 Max 性能定制级内存预读取技术**，为您带来极致流畅的使用体验。

## 🌟 核心独家特性

* **内存预加载极速架构**：为大内存设备（如 Mac M4 Max）量身定制，先将高质量抓取图流转入高速统一内存（`BytesIO` Buffer）中并在后台预处理。当您点击"确定保存"时，瞬间写入物理硬盘，告别边看边挂机缓冲的网络卡顿。
* **沉浸式画廊挑选 UI**：采用自适应宽度的并排缩略图网格界面。在下载之前，赋予用户全盘控制力，您可以逐张审视文件大小并精确勾选。
* **键盘快捷挑图模式**：点击任意图片即可全屏查看大图，完全支持通过方向键 `←` 和 `→` 进行轮播穿梭，看到满意的按 `Space`（空格键）即可勾选，操作极其顺滑。
* **SKU 规格图自动采集**：针对多规格商品，程序会自动逐一模拟点击页面上每一个规格选项，捕获切换后的主图，并以规格名称命名，合并进画廊统一审核。
* **🚀 (New) SKU 翻译审核系统**：在将翻译写入图片之前，引入了一个全新的交互式审核环节。
    * **交互式表格编辑器**：在一个精美的表格界面中，左右对照查看中文原名与翻译结果，支持直接手动修改。
    * **智能查找替换**：支持一键批量查找和替换原始中文名称，方便统一修改规格词（如将所有“颜色分类”改为“Color”）。
    * **单条/批量翻译控制**：可以一键执行全量翻译，也可以对单条记录进行重新翻译。
    * **精简操作流**：所有的重载、保存、翻译和最终写入操作均集成在顶部单行操作栏，布局紧凑高效。
    * **智能路径预填**：(New) 打开翻译界面时，系统会自动扫描下载目录，智能填入最近一次抓取生成的 SKU 文本地址，无需手动寻找路径。
* **流程快捷跳转**：(New) 抓取任务完成后，如果下载了规格图片，进度页会自动显示“写英文标题”快捷按钮，一键直达翻译审核界面。
* **规格图自适应英文贴标**：调用阿里云电商专用翻译接口，将规格名翻译成精准英文。程序会在原图底部自动压上和谐色带，并具备**自适应字体大小**功能，确保英文标题完美契合图片宽度。

## 🛠 强大功能支撑

* **全面数据提取**：精准区分「详情图」、「主图」、「主副视频」、「规格图」，同时爬取商品规格与交易属性参数。
* **智能反爬应对**：搭载 Playwright Stealth。当阿里系统弹出验证码时，能敏锐识别并拉起提示音，指引您在界面上手动过关。
* **OCR 文本识别兜底**：当网页渲染异常时，自动截图并动用 Tesseract OCR 文字识别引擎抢救文本。
* **一键直达抽屉**：成功下载后，日志附带超级链接，点击即可直达本地目标文件夹！

## 📁 目录与输出结构

默认所有的文件将被分类至用户目录下的 `Downloads/Taobao_Data` 内：
* **独立商品文件夹**：以 `[商品ID]_[商品标题]` 明确命名。
* **精美图库** (`images/`)：所有勾选过的主图、详情图分开命名存放。
* **规格图库** (`images/sku/`)：存放带英文贴标的 SKU 效果图。
* **属性总览** (`info.txt`)：保存原始链接、抓取时间和详尽规格文字版。

## ⚙️ 环境和依赖

使用前建议确保本地已经成功配置/安装以下环境：
- Python 3.8+ 
- `playwright` (执行 `playwright install chromium`)
- `alibabacloud-alimt20181012` (阿里云翻译 SDK)
- `opencv-python` (视频处理)
- `tkinter` (标准库，用于 GUI)
- （可选推荐）Tesseract-OCR (用于文本识别增强)
