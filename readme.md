# 淘宝/天猫商品数据抓取助手

这是一个基于 Python 的自动化工具，用于一键提取淘宝和天猫商品页面上的详细数据和媒体资源。本工具提供了友好的图形用户界面（GUI），底层使用 Playwright 配合自动翻页技术抓取数据，并使用了多重兜底策略确保数据的完整性。

## 主要功能特点

* **全面数据提取**：自动抓取商品的主图、详情图、主图视频以及核心属性参数信息。
* **可视化操作界面**：基于 Tkinter 开发了直观的桌面 GUI，支持同时粘贴多个商品 URL 批量处理，且能实时展示每个商品的下载进度详情。
* **智能反爬与拦截应对**：
  * 搭载 Playwright Stealth 增强隐蔽性，伪装无头浏览器特征。
  * 自动检测滑块、验证码、甚至被重定向至登录页等安全拦截动作，检测到后立刻弹窗及声音警报，提醒用户在浏览器中手动协助完成验证。
* **OCR 文本识别兜底**：当商品页 DOM 结构变化导致直接获取属性参数失败时，工具将自动对参数区域网页截图，并调用 Tesseract OCR 对进行图片文字识别，进一步保障数据获取成功率。
* **高效稳定的下载机制**：
  * 支持自动下载图片，并统一转为标准 JPEG 格式进行质量优化。
  * 利用流式分块写入机制稳定拉取大体积 MP4 视频文件，防范中途断流。
* **友好的用户体验**：
  * **提示音效**：支持 macOS 与 Windows，下载成功或失败会播放相应的简短音效以作提示。
  * **一键直达**：下载完成后，在工作界面的日志中生成支持点击的跳转链接，一键打开本机对应的资源文件夹。
  * **持久化管理**：运行记录实时存储至 `download.log`，同时自动管理解析过的链接地址历史于 `urls_history.txt`，方便后续追溯。

## 目录与输出结构

默认情况，所有的文件将自动被保存于用户目录下的 `Downloads/Taobao_Data` 内：
* **独立文件夹**：以 `[商品ID]_[防特殊字符处理的标题]` 规范命名。
* **图片目录** (`images/`)：所有轮播图（`main_x.jpg`）与长图详情（`desc_x.jpg`）分开命名存放。
* **视频文件**：主视频（如果有）以 `video_x.mp4` 落盘商品文件夹根级别。
* **属性文件** (`info.txt`)：清晰规整地保存目标原始链接、抓取时间和详细文字版规格属性。

## 环境和依赖

使用前建议确保本地已经成功配置/安装以下环境：
- Python 和相关包管理环境。
- `playwright` 及其相关浏览器环境 (`playwright install chromium`)。
- （可选但在兜底策略中强烈建议）已安装并配置好 Tesseract-OCR 以及对应中文字库的 `pytesseract` 环境。
